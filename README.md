# Number Guessing Game (C# Console)
https://roadmap.sh/projects/number-guessing-game

**Number Guessing Game** is a C# console game where the player must guess a randomly generated number between **1 and 100**.  
The game includes **3 difficulty levels**, each with a different number of attempts:

- **Easy:** 10 chances  
- **Medium:** 5 chances  
- **Hard:** 3 chances  

---

# How It Works

1. The program automatically generates a random number between 1 and 100.
2. The player selects a difficulty level.
3. The player tries to guess the number.
4. After each guess, the game tells the player whether the secret number is:
   - Greater than the entered number
   - Less than the entered number
5. The game ends when:
   - The player guesses correctly
   - All attempts are used

---

# Requirements

- .NET SDK installed (recommended .NET 6 or later)
- Visual Studio, Visual Studio Code, or terminal with `dotnet`
